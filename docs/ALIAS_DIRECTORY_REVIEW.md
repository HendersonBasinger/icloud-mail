# 目录数量与旧创建候选

“Apple 目录”显示最近一次成功同步中、转发到当前主号的隐藏邮箱数量，以及快照时间。它与“本地记录”分别统计：本地还可能保留历史地址、停用地址和未确认候选。目录暂未发现某个地址，不等于已经取得删除回执，因此同步不会按差额删除地址、凭据、邮件或 Pool 租约。

已知来自 Apple Account 通道、尚无完成 ID 的候选，若超过 24 小时，创建恢复会先核对本次 iCloud Web 与 Apple Account 两份完整目录。只有两份有效目录均精确缺失原地址，才把候选隔离为“待复核”。此路径不重发原候选的完成请求，后续创建不再被该候选阻塞。

隔离不表示创建失败或上游删除成功。原地址、ID、密文凭据和容量占用继续保留，凭据不对外发行。若后续同步精确发现该地址已启用且转发到此主号，则在事务中恢复原 ID 与原凭据、解除待复核，不生成替代凭据。

较新的候选、已有完成 ID 的候选、目录读取异常、账户归属不符或信息不完整，仍沿原确认流程处理。创建预算、另一通道、Pool 使用及退役状态不因候选隔离而重置。

管理员账户接口新增可选 `apple_directory`：`source`、`observed_at`、`total`、`active`、`inactive`、`local_missing` 为最后成功目录快照；`review_pending` 为当前待复核候选数。原 `alias_count` 仍表示本地记录总数。快照与账户身份绑定，账户身份改变后隐藏旧快照。

同步响应可附 `summary.directory_warning`：统计快照或候选核对暂未完成时，已导入地址与其凭据仍作为成功结果返回，不要求重发创建操作。`reviewed_count` 表示本次从目录恢复的旧候选数量。
